# Micropia v11.0 - El Zoo Invisible

Experiencia educativa interactiva BSL-4 sobre los microorganismos mas letales de la historia.

## Caracteristicas v11.0

- **Landing Page**: Retrato de cientifica, microscopio, logo oficial, titulo con neon amarillo
- **Sala de Contencion**: 5 tubos con animaciones horror, guardia NPC con chismes, navegación a todas las salas
- **Mapa Global**: Mapa de alta resolucion con hotspots (Argentina, Brasil, Shark Bay, Biotecnófilos)
- **Laboratorio del Estomago**: Scanner corporal, Teoría del Holobionte, análisis de vulnerabilidades
- **Sala de Vectores**: Anatomia interactiva de la pulga real (PULGA.jpg), conexion con Peste Negra
- **Mision Hantavirus**: Juego detective con videos YouTube reales (2GSpRnulPis, 1rLIyzZwHTA)
- **Sala Cianobacterias**: Estromatolitos animados, Shark Bay, El Primer Aliento
- **Isla Biotecnófilos**: Biopelículas, Quorum Sensing, tema neón púrpura/azul TikTok
- **Quiz 3 Niveles**: Bronce/Plata/Oro con preguntas expertas sobre Hantavirus
- **Visor 3D**: Modelos procedurales de bacteria de peste y pulga con Three.js
- **Oficina Dra. Micra**: Expedientes secretos interactivos
- **Navegación**: Botones 'Siguiente Sala' en todas las salas para loop continuo

## Stack

- React 18 + Vite 6
- Framer Motion
- Three.js / React Three Fiber
- TailwindCSS v4
- Vitest

## Comandos

```bash
npm install
npm run dev     # Servidor de desarrollo
npm run build   # Build de produccion
npm test        # Tests
```
